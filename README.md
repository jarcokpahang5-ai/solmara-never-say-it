# Never Say It Out Loud

One line you should never, ever say out loud — the worst possible thing to blurt in a quiet lift, a job interview, or a wedding. This entry is for the [make.fun bounty "Never Say It Out Loud"](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd).

Run it:

```sh
python3 main.py
```

It prints exactly one funny line — a best man's confession, delivered at the worst possible moment: in a lift, moments before a wedding.
